# طيف 🎨

مكتبة ألوان وواجهات طرفية للغة **سولان**. تجمع في مكتبة واحدة أفضل ما في مكتبات الألوان والطرفية الشهيرة
(chalk · rich · colorama · gradient-string · chalk-animation · chroma.js · culori · boxen · cli-table · ora · cli-progress · asciichart · cli-spinners)
مع دعم حقيقي للعربية: عرض الحروف المشكَّلة، أسماء الألوان العربية، وتلوين الكلمات بدل الحروف لحفظ وصل الحروف.

## التثبيت

```bash
solan add kingxsolo/taif
```

```
استورد "طيف"
اطبع(طيف.احمر("مرحباً"))
// أو
من "طيف" استورد تدرج, اطار, جدول
```

## البدء السريع

```
استورد "طيف"

اطبع(طيف.نمط("غامق احمر على ابيض")(" خطأ "))          // نمط نصي مثل rich
اطبع(طيف.وسوم("[#ff8800]برتقالي[/] و [تدرج:غروب]تدرج[/]"))   // وسوم
اطبع(طيف.تدرج("نص ملوّن", ["#f43f5e", "#06b6d4"]))            // تدرج
اطبع(طيف.اطار("مرحباً", {"نمط": "مدور", "عنوان": "طيف"}))     // إطار
اطبع(طيف.تنبيه("نجاح", "تم الحفظ"))                            // تنبيه
```

جرّب العرض الكامل: `solan examples/عرض.سو` والحركات: `solan examples/حركات.سو`.

## 1) المستويات والتخفيض التلقائي

يكتشف طيف قدرة الطرفية تلقائياً: `0` بلا ألوان · `1` ستة عشر · `2` مئتان وستة وخمسون · `3` ألوان حقيقية (24 بت).
أي لون تطلبه يُخفَّض تلقائياً إلى ما تدعمه الطرفية (الأقرب لوناً)، فالكود نفسه يعمل في Termux وVS Code وSSH وCI.

| الدالة | الوظيفة |
|---|---|
| `مستوى()` · `ضبط_المستوى(0..3)` | قراءة/فرض المستوى |
| `ضبط(صح/غلط)` | تفعيل أو تعطيل الألوان |
| `كشف_المستوى()` | إعادة الكشف من البيئة |
| `قارن_المستويات(مصدر)` | يعرض التدرج نفسه بالمستويات الثلاثة |

متغيرات البيئة المحترمة: `NO_COLOR` (تعطيل) · `FORCE_COLOR=0..3` · `COLORTERM` · `TERM` · `COLUMNS`.
وإن لم تكن المخرجات طرفية (أنبوب، ملف) تُطبع النصوص بلا أكواد تلقائياً.
المكتبة لا تنهار إن مُنعت صلاحيتا `بيئة`/`تنفيذ`؛ تعود لقيم افتراضية.

## 2) الأنماط

```
طيف.احمر("نص")                       // دوال جاهزة: اسود احمر اخضر اصفر ازرق بنفسجي سماوي ابيض رمادي
طيف.احمر_فاتح("نص")                  // الفاتحة: ..._فاتح
طيف.خلفية_ازرق("نص")                 // الخلفيات: خلفية_...
طيف.غامق(...)  خافت  مائل  مسطر  وميض  معكوس  مخفي  مشطوب  فوق_خط  مسطر_مزدوج

خل خطأ = طيف.نمط("غامق احمر على ابيض")    // نمط قابل لإعادة الاستعمال
خل عنوان = طيف.نمط("#38bdf8", "مسطر")     // أكثر من وسيط
طيف.rgb(255, 136, 0, "نص")  طيف.هيكس("#f80", "نص")  طيف.hsl(30, 1, 0.5, "نص")
طيف.لون256(208, "نص")       طيف.خلفية_هيكس("#222", "نص")
طيف.لون_من("قرمزي", "نص")   طيف.شارة_لون("#ffd700", " ذهبي ")   // خلفية + نص مقروء تلقائياً
```

**ما يقبله النمط:** أسماء ANSI (`احمر` · `bright_red`) · أسماء CSS الـ148 · الأسماء العربية (`قرمزي` `زمردي` `فيروزي` `خزامي` ...)
· `#rgb` `#rrggbb` · `rgb(...)` · `hsl(...)` · `oklch(...)` · `ansi:N`. الخلفية بـ `على لون` أو `bg_لون` أو `خلفية_لون`.
تُطبَّع الهمزات والتاء المربوطة والتشكيل، فـ«أحمر» = «احمر».

- **آمنة للتداخل:** `احمر("أ" + ازرق("ب") + "ج")` يعيد الأحمر لـ«ج» (إغلاق/إعادة فتح لكل نمط على حدة كما في chalk).
- **متعددة الأسطر:** كل سطر يُلَفّ وحده فلا تتسرب الخلفيات بين الأسطر.
- نمط مجهول يرمي خطأً عند الإنشاء، لا عند الطباعة.

## 3) الألوان ككائنات (`لون`)

```
خل ل = طيف.لون.من_نص("#6366f1")       // هيكس · rgb() · hsl() · أسماء CSS · أسماء عربية
ل.هيكس()  ل.rgb()  ل.hsl()  ل.hsv()  ل.hwb()  ل.cmyk()  ل.lab()  ل.lch()  ل.oklab()  ل.oklch()  ل.css("oklch")
```

**المنشئات:** `من_هيكس` `من_rgb` `من_hsl` `من_hsv` `من_hwb` `من_lab` `من_lch` `من_oklab` `من_oklch` `من_cmyk` `من_مساحة(م, قائمة)`
`من_درجة_حرارة(كلفن)` `عشوائي_لون()` `عشوائي_جميل()`.

**المزج** (`امزج(آخر, نسبة, مساحة)`): المساحات `rgb · linear · hsl · hsv · hwb · lab · lch · oklab · oklch`.
الافتراضي `oklab` (الأنعم إدراكياً). الألوان الدائرية (hsl/lch/oklch) تمزج بأقصر قوس. وما يخرج عن نطاق sRGB يُعاد داخله بتقليل الكروما (gamut mapping) بدل القص.

```
ل.امزج(طيف.لون.من_نص("#ef4444"), 0.3)            // 30% من الأحمر
ل.امزج(آخر, 0.5, "oklch")
طيف.مزج("#f00", "#00f", 0.5, "lch")              // اختصار للنصوص
```

| التعديل | |
|---|---|
| `افتح(ك)` `اغمق(ك)` `اشبع(ك)` `اضعف(ك)` `لف(درجات)` | HSL |
| `رمادي()` `اعكس()` `مكمل()` `شفافية(ش)` `ركب(خلفية)` | |
| `عدل(مساحة, فهرس, قيمة, نسبي)` | تعديل أي قناة في أي مساحة |
| `دمج_وضع(آخر, وضع)` | `multiply screen overlay hardlight softlight darken lighten difference exclusion dodge burn` (وبالعربية: `ضرب شاشة تراكب ...`) |
| `تناسق("ثلاثي"\|"رباعي"\|"مكمل"\|"مجاور"\|"مكمل_منقسم")` | ألوان متناسقة |
| `درجات(ن)` | من الفاتح إلى الغامق عبر اللون |

**الوصولية:** `لمعان()` · `تباين(آخر)` (WCAG) · `نص_مناسب()` (أسود أو أبيض) · `اجعل_مقروءا(خلفية, 4.5)` · `فرق(آخر, "oklab"|"lab")` · `اقرب_اسم()` · `هل_فاتح()`.

## 4) التدرجات

```
طيف.تدرج("نص", "غروب")                                    // اسم جاهز
طيف.تدرج("نص", ["#f43f5e", "#8b5cf6", "#06b6d4"])         // محطات
طيف.قوس_قزح("نص")   طيف.تدرج_خلفية("نص", "بحر")
طيف.تدرج("مرحبا بالعالم", "نار", {"وضع": "كلمة"})          // مهم للعربية: يحفظ وصل الحروف
```

**الخيارات:** `وضع` (`حرف` · `كلمة` · `سطر`) · `اتجاه` (`افقي` · `عمودي` · `قطري` للنص متعدد الأسطر) · `مساحة` · `خلفية` · `ازاحة` (للحركة) · `دوري` · `ارتداد`.

**جاهزة (26):** `قوس_قزح باستيل اطلس كريستال مراهق عقل صباح نائب شغف فاكهة انستغرام قديم صيف غروب بحر نار غابة نيون سايبر ذهب ليل شفق واحة صحراء جليد حرارة`
(وبالإنجليزية: `sunset ocean fire forest neon ...`). `اسماء_التدرجات()` تعرضها.

`سلم(مصدر, ن)` قائمة ألوان · `لون_عند(مصدر, ت)` لون واحد · `شريط_تدرج(مصدر, عرض)` شريط للمعاينة.

## 5) الوسوم

```
طيف.وسوم("[احمر غامق]خطأ[/] عادي [#ff8800 مسطر]برتقالي[/] [قرمزي على كحلي]ملوّن[/]")
طيف.وسوم("[تدرج:غروب]نص[/]")   طيف.وسوم("[تدرج:#f00,#00f]نص[/]")
```

`[[` و`]]` للأقواس الحرفية · `اهرب(نص)` لحماية نص المستخدم · `الغ_الوسوم(نص)`.
ما بين الأقواس ولا يُفهم نمطاً يبقى حرفياً (`[1, 2]` · `[add]`).

## 6) واجهة الطرفية

```
طيف.اطار(نص, {نمط, عنوان, تذييل, حشو, حشو_راسي, هامش, عرض ("كامل" او رقم), محاذاة,
               محاذاة_عنوان, لون_الاطار, لون_النص, لون_العنوان, خلفية})
```
أنماط الإطار: `مفرد مزدوج مدور ثقيل متقطع مفرد_مزدوج كتلي اسكي فارغ` (وبالإنجليزية `round bold double ...`).

| | |
|---|---|
| `جدول(صفوف, {رؤوس, نمط, محاذاة, حشو, خطوط_صفوف, مخطط, الوان_اعمدة, لون_رأس, لون_الاطار, عنوان, عرض_اقصى})` | خلايا متعددة الأسطر، أرقام لليمين، تقليص تلقائي لعرض الطرفية |
| `خط(عنوان, عرض, حرف, محاذاة, لون)` | فاصل بعنوان |
| `قائمة(عناصر, {مرقمة})` | تدعم التداخل بقائمة داخل قائمة |
| `شجرة(قاموس_او_قائمة, {عنوان})` | ├── └── |
| `شارة(نص, لون)` | خلفية ملونة + نص مقروء تلقائياً |
| `تنبيه("نجاح"\|"خطأ"\|"تحذير"\|"معلومة", نص, عنوان)` | إطار بألوان السمة |
| `شريط_نسبة(نسبة, عرض, {نمط, تدرج, لون})` · `شريط_تقدم(...)` | أنماط: `كتل ناعم خطوط نقاط مربعات اسهم اسكي` |
| `شريط(اجمالي, {وصف, عرض, نمط, تدرج})` | شريط حيّ: `.حدّث(ق)` `.تقدم(ن)` `.اتمم()` مع الوقت والمتبقي |
| `رابط(نص, url)` | رابط قابل للنقر (OSC 8) |
| `طول_مرئي` `ازل` `قص` `املأ` `لف_نص` `احرف` | أدوات نصوص تفهم ANSI والعربية المشكّلة والرموز العريضة |

المحاذاة: `"يسار"` · `"يمين"` · `"وسط"` (اتجاه الشاشة الفعلي).

## 7) الحركات والدوارات

تعمل في الطرفية الحيّة فقط؛ وفي غيرها تطبع الإطار النهائي مرة واحدة (آمنة لملفات السجل وCI).

```
طيف.قوس_قزح_متحرك("نص", 3)       طيف.تدرج_متحرك("نص", "نار", 3)
طيف.نيون("نص", "#22d3ee", 2)      طيف.نبض("نص", "#fb7185", 2)
طيف.تشويش("نص", 1.5)              طيف.كتابة("نص", 0.04, "سايبر")
طيف.رادار("نص", 2)                طيف.كاراوكي("نص", 3)
طيف.موجة("نص", "بحر", 3)          طيف.تلاشي("نص", "#fff", 1.5, "ظهور"|"اختفاء")

طيف.شغل_حركة(دالة(ي) { ارجع "إطار " + نص(ي) }, 40, 0.05)    // حركتك الخاصة
```

**الدوار** (مع حلقة الأحداث):

```
خل د = طيف.دوار("جاري التحميل", {"نمط": "نقاط", "تدرج": "بحر"})
د.ابدأ();  د.حدث("جاري التجهيز");  د.انجح("تم")     // او د.افشل("..") د.حذر("..") د.معلومة("..")

// أو مباشرة مع عمل غير متزامن:
خل نتيجة = انتظر طيف.مع_دوار("تحميل", غير_متزامن دالة() { انتظر نم(1); ارجع 42 })
```

أنماط الدوار: `نقاط نقاط2 خط قوس دائرة ارتداد اسهم نمو مربع مثلث نجمة نقاط_بسيطة شريط قمر ساعة نبض`، أو `{"اطارات": [...], "مدة": 0.1}`.

> المؤشر يُخفى أثناء الحركة ويُعاد عند انتهائها أو عند الخطأ. إن قتلت البرنامج بـ Ctrl+C في منتصف حركة قد يبقى المؤشر مخفياً (اكتب `reset`).


## 9) المعاينة

`معاينة(لون)` بطاقة بكل الفضاءات والتباين وأقرب اسم · `لوحة(الوان)` · `طيف_كامل()` · `عرض_256()` · `تشخيص()` تقرير عن الطرفية.

## 10) السمات

```
طيف.ضبط_سمة("دراكولا")        // افتراضي · دراكولا · نورد · مونوكاي · سولارايزد · جروفبوكس · كاتبوتشين · طوكيو
طيف.ضبط_سمة({"نجاح": "#00ff88"})   // تعديل أدوار
طيف.دور("نجاح")("نص")             // الأدوار: نجاح خطأ تحذير معلومة مميز خافت نص اساسي خلفية
طيف.نجاح("تم")  طيف.خطأ("فشل")  طيف.تحذير("..")  طيف.معلومة("..")
```

بيانات جاهزة: `اسماء_css` · `اسماء_عربية` · `تدرجات_جاهزة` · `لوحة_مواد` · `لوحة_تيلويند` · `سمات_جاهزة` · `رموز`.

## ملاحظات العربية

- العرض المرئي يتجاهل التشكيل (`عَرَبِيّ` = 4) ويحسب الرموز العريضة (😀 = 2) فتبقى الإطارات والجداول متراصة.
- تلوين **كل حرف** على حدة قد يكسر وصل الحروف في الطرفيات التي تشكّل العربية. استعمل `{"وضع": "كلمة"}`؛ وهو ما تفعله وسوم `[تدرج:...]` تلقائياً.
- كثير من الطرفيات لا تدعم الاتجاه من اليمين لليسار؛ المكتبة تقيس وتحاذي منطقياً ولا تعكس الترتيب.
- أسماء الألوان العربية تُبحث بعد تطبيع الهمزات: `أخضر داكن` = `اخضر_داكن`.
